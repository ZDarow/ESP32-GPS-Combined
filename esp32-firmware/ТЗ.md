## 4. Создание проекта из шаблона

### Вариант А: через `idf.py` (рекомендуемый)
Находясь в `C:\Users\Mi\Ublox\esp32s3-gnss-ESP-IDF`:
```powershell
idf.py create-project --template blink .
```

### Вариант Б: через VS Code
1. Открыть VS Code.
2. `Ctrl+Shift+P` → `ESP-IDF: New Project`.
3. Указать:
   - **Project name:** `esp32s3_gnss`
   - **Location:** `C:\Users\Mi\Ublox\esp32s3-gnss-ESP-IDF`
   - **Board:** `ESP32-S3-DevKitC-1`
   - **Template:** `blink` или `hello_world`
4. Нажать **Create Project**.

### Вариант В: копирование из examples
```powershell
xcopy /E /I $env:IDF_PATH\examples\get-started\hello_world .
```

## 5. Настройка таргета ESP32-S3

В директории проекта выполнить:
```powershell
idf.py set-target esp32s3
```

⚠️ Эта команда пересоздаёт `sdkconfig`. Выполнять до ручных правок.

### Проверка
В `sdkconfig` должны появиться строки:
```
CONFIG_IDF_TARGET="esp32s3"
CONFIG_IDF_TARGET_ESP32S3=y
```

## 6. Конфигурация проекта под железо

### 6.1. Запуск menuconfig
```powershell
idf.py menuconfig
```

### 6.2. Обязательные параметры

| Раздел | Параметр | Значение |
| :--- | :--- | :--- |
| **Serial flasher config** | Flash size | `16 MB` |
| **Serial flasher config** | Flash SPI mode | `QIO` |
| **Serial flasher config** | Flash SPI speed | `80 MHz` |
| **Component config** → **Bluetooth** | Enable Bluetooth | `y` |
| **Component config** → **Bluetooth** | Bluetooth Host | `NimBLE` |
| **Component config** → **USB** | USB CDC on boot | `y` |
| **Component config** → **Log output** | Default log verbosity | `Info` |
| **Component config** → **FreeRTOS** | Tick rate | `1000 Hz` |

### 6.3. Сохранение
В menuconfig: `S` → сохранить в `sdkconfig` → `Q` → выход.

## 7. Структура проекта под GPS/GNSS трекер

Агент создаёт внутри `C:\Users\Mi\Ublox\esp32s3-gnss-ESP-IDF` следующую структуру:

```
esp32s3-gnss-ESP-IDF/
├── CMakeLists.txt
├── sdkconfig
├── partitions.csv              # Таблица разделов под 16 MB
├── main/
│   ├── CMakeLists.txt
│   ├── main.c                  # Точка входа
│   ├── app_config.h            # Общие константы (пины, UUID, интервалы)
│   ├── gps_uart.c              # UART-драйвер NEO-7M (GPIO16/17)
│   ├── gps_uart.h
│   ├── ble_nus.c               # BLE Nordic UART Service
│   ├── ble_nus.h
│   ├── power_manager.c         # Light Sleep / Deep Sleep
│   ├── power_manager.h
│   ├── battery_adc.c           # Чтение заряда 18650 через ADC1 (GPIO2)
│   └── battery_adc.h
└── components/
    └── nmea_parser/
        ├── CMakeLists.txt
        ├── include/
        │   └── nmea_parser.h
        └── src/
            └── nmea_parser.c
```

### 7.1. Фиксация пинов в `main/app_config.h`
```c
#pragma once

#define GPS_UART_TX_PIN     17
#define GPS_UART_RX_PIN     16
#define GPS_UART_BAUD       9600
#define BATTERY_ADC_PIN     2      // Только ADC1!
#define DEEP_SLEEP_BTN_PIN  0
```

## 8. Настройка VS Code для проекта

### 8.1. Открыть папку проекта
`File → Open Folder` → выбрать `C:\Users\Mi\Ublox\esp32s3-gnss-ESP-IDF`.

### 8.2. Проверить настройки расширения ESP-IDF
`Ctrl+Shift+P` → `ESP-IDF: Extension Settings`:
- **Idf: Port** — выбрать COM-порт платы (уточнить в Диспетчере устройств).
- **Idf: Flash Type** — `UART`.
- **Idf: Target** — `esp32s3`.

После первой сборки VS Code подтянет пути к заголовкам ESP-IDF. Если IntelliSense не работает:
`Ctrl+Shift+P` → `ESP-IDF: Add VS Code Configuration`.

## 9. Сборка и проверка

### 9.1. Сборка
```powershell
idf.py build
```
Ожидаемый результат: `Project build complete`, файл `build/esp32s3_gnss.bin`.

### 9.2. Определение COM-порта платы
**Диспетчер устройств** → **Порты (COM и LPT)** → найти `USB-SERIAL CH340 (COMx)` или `USB-JTAG/serial debug unit (COMx)`.

### 9.3. Прошивка
```powershell
idf.py -p COMx flash
```
Заменить `COMx` на реальный порт.

### 9.4. Мониторинг
```powershell
idf.py -p COMx monitor
```
Выход: `Ctrl+]`.

### 9.5. Комбо-команда
```powershell
idf.py -p COMx build flash monitor
```

## 11. Специфика Windows 10 — типичные проблемы

| Проблема | Решение |
| :--- | :--- |
| `idf.py` не найдена | Использовать ярлык **ESP-IDF PowerShell**, не обычный |
| Ошибка скриптов PowerShell | От админа: `Set-ExecutionPolicy -Scope CurrentUser RemoteSigned` |
| `COMx` не найден при flash | Проверить data-кабель, переткнуть USB, Диспетчер устройств |
| `Permission denied` на COM | Закрыть Arduino IDE и другой софт, занимающий порт |
| Антивирус блокирует сборку | Добавить `C:\Users\Mi\Ublox\` и `C:\Espressif\` в исключения |
| Плата не входит в режим загрузки | Зажать `BOOT` → нажать `RST` → отпустить `BOOT` → повторить flash |
| Долгая первая сборка | Нормально: первый build на Windows занимает 5-10 минут |
